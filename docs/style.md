Design System
- Centralize colors, typography, spacing, borders, radii, shadows, and component dimensions in design tokens.
- Reuse existing styling frameworks and libraries where appropriate.
- Use consistent layouts, content widths, responsive breakpoints, and section spacing.
Components
- Reuse shared buttons, form controls, cards, tables, badges, dialogs, navigation, and page layouts where appropriate.
- Keep sizing, typography, and behavior consistent.
- Define reusable loading, empty, error, and validation states.
Interaction and Accessibility
- Maintain consistent hover, focus, active, disabled, and validation states.
- Ensure keyboard accessibility, visible focus indicators, semantic markup, and sufficient contrast.
Rules
- Prefer existing tokens and components over hardcoded values and duplicated styles.
- Avoid arbitrary one-off styling and unnecessary dependencies.
- Extend the system deliberately when new requirements arise.
- Follow this guide for every new or modified page.
- Update this guide when established styling conventions change.
